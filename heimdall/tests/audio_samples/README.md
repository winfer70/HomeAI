# Heimdall STT benchmark audio samples

These WAV files are synthetic Windows SAPI-generated placeholder clips for latency timing only, **not** accuracy testing. Replace them with real human-recorded Polish and English clips before using this benchmark for STT model accuracy comparisons.

Current placeholder set:

- `en_light_command.wav`
- `en_temperature_query.wav`
- `pl_light_command.wav`
- `pl_temperature_query.wav`

The clips were synthesized on Windows using installed SAPI voices and are intended only to give the benchmark script deterministic short inputs.
